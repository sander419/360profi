# 360PROFI · Внутренний штаб

Демо внутреннего операционного штаба для 360PROFI: проекты, задачи, оборудование и команда
в одном окне. Прототип для показа — работает целиком в браузере, без сервера и без входа.

**Демо:** https://sander419.github.io/360profi/

## Что показывает

| Раздел | Что внутри |
| --- | --- |
| Штаб · обзор | Сводка дня: активные проекты, ближайшие сроки, просрочки, склад, загрузка команды, лента событий |
| Проекты | Готовность проекта по 5 осям (команда, оборудование, логистика, контент, документы), чек-листы, бюджет и расходы, гант |
| Задачи | Канбан + гант, фильтры, подзадачи, правила автоматизации |
| Оборудование | Склад: статусы (на складе / на проекте / в ремонте / резерв / в пути), привязка к проектам |
| Команда | Компетенции, допуски, загрузка, доступность |
| В разработке | База знаний, 360 Academy, разборы ошибок, аналитика — заглушки |

## Ограничения прототипа

Это демо, а не система для реальной работы:

- **Данные живут в `localStorage` браузера.** У каждого зрителя своя копия, между устройствами
  ничего не синхронизируется, чистка данных сайта всё стирает.
- **Нет входа, ролей и прав** — любой, кто открыл ссылку, видит и меняет всё.
- **Нет сервера и API.** AI-функций пока нет, хотя `@google/genai` лежит в зависимостях.

Для пилота на реальных сотрудниках нужен бэкенд, авторизация и роли — это отдельный этап.

## Демо-данные

Сид сеется относительно дня первого открытия, а при загрузке даты автоматически сдвигаются
на число прошедших дней — сроки не «протухают», если демо открыли неделю назад.
Кнопка **«Сброс демо»** в шапке возвращает исходное состояние.

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
```

Другие команды:

```bash
npm run typecheck    # tsc --noEmit
npm run build        # сборка в dist/ для корня домена
npm run deploy       # сборка с base=/360profi/ и публикация на GitHub Pages
```

`npm run deploy` пушит содержимое `dist/` в ветку `gh-pages`; GitHub Pages раздаёт её
по адресу выше. Ветка `main` — исходники, `gh-pages` — только собранный результат.

## Стек

React 19 · TypeScript · Vite 6 · Tailwind 4 · Recharts · Motion · lucide-react.
Состояние — один React-контекст (`src/context/AppContext.tsx`), данные — `src/data/seedData.ts`.

## Структура

```
src/
  components/
    views/       — экраны: Штаб, Проекты, Задачи, Оборудование, Команда, «Скоро»
    projects/    — карточка готовности, гант проектов
    tasks/       — канбан, гант задач, правила автоматизации
    team/        — карточки сотрудников, доступность
    common/      — аватары, прогресс, подсветка поиска
  context/       — AppContext: состояние, действия, персист в localStorage
  data/          — сид-данные и хелперы дат
  utils/         — экспорт CSV, бюджетные алерты, звуки
public/img/      — обложки проектов (локальные, чтобы демо не зависело от внешних CDN)
```
